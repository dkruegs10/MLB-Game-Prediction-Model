# MLB-Game-Prediction-Model
MLB Game Prediction Model

This project builds a machine learning model to predict MLB game winners
using historical team, lineup, bullpen, and starting pitcher statistics.

The model:
• Engineers matchup-based features
• Uses Random Forest classification
• Applies SMOTE to balance training data
• Generates probability predictions for today's games

Tools:
Python, pandas, NumPy, scikit-learn
